# ชุดสกิลตัดคลิปแนวตั้ง (reel-cut) สำหรับ Claude Code

สั่งภาษาไทยธรรมดา เช่น "ตัดคลิปล่าสุดใน Downloads ให้หน่อย" แล้ว Claude จะ ถอดเสียง → ตัดช่วงเงียบ/เทคผิด → ใส่ข้อความและอนิเมชัน → ใส่เสียงเอฟเฟกต์ → ส่งไฟล์ให้
(สำหรับ **Mac** ที่ใช้ **Claude Code**)

## ติดตั้ง (ทำครั้งเดียว)
เปิด Claude Code แล้วคัดลอกประโยคนี้ไปวาง:

> ติดตั้งสกิลตัดคลิปจาก https://github.com/Theeratikorn/reel-cut-skills.git ให้หน่อย ทำตามไฟล์ INSTALL.md

แล้วตอบ "ได้" เมื่อ Claude ถาม จากนั้น **Claude จะถามคุณก่อนว่าคุณเป็นใคร ทำคอนเทนต์เรื่องอะไร ชอบสี/สไตล์แบบไหน** (ตอบสั้นๆ ข้ามได้) เพื่อตั้งค่าให้ผลงานเป็นของคุณเอง ที่เหลือ Claude ทำให้เอง (ใช้เวลาประมาณ 10–20 นาที ถ้าเครื่องยังไม่มีโปรแกรมตัดต่อ)

## สิ่งที่ต้องมี
- Mac ที่ลง Claude Code แล้ว
- อินเทอร์เน็ต
- บัญชี [ElevenLabs](https://elevenlabs.io) (ใช้ถอดเสียงภาษาไทย **มีค่าใช้จ่ายตามการใช้งาน**) — เตรียม API key ไว้ Claude จะบอกวิธีเอง

## ใช้งาน
พิมพ์คำสั่งปกติ เช่น
- "ตัดคลิปล่าสุดใน Downloads ให้หน่อย"
- "ตัดคลิป xxx.mp4 แบบเรียบๆ แค่ตัดช่วงเงียบกับใส่ข้อความ"
- "ลองเปลี่ยนสไตล์เป็นแบบลายมือ"

ไฟล์ที่เสร็จอยู่ที่ `~/Movies/ReelCut` (หรือโฟลเดอร์ CapCut เดิมถ้ามี)

## อัปเดต / มีปัญหา
พิมพ์ "อัปเดตสกิลตัดคลิป" หรือ "ตรวจเครื่องให้หน่อยว่าทำไมตัดคลิปไม่ได้"

## หมายเหตุ
- ชุดนี้ไม่มีชื่อ/แบรนด์ของใครติดมา ข้อความทั้งหมดมาจากสิ่งที่คุณพูดในคลิปและสิ่งที่คุณตอบตอนตั้งค่า (เปลี่ยนทีหลังได้: พิมพ์ "เปลี่ยนสีหลัก" หรือ "เปลี่ยนข้อความท้ายคลิป")
- เพลงพื้นหลังและเสียงเอฟเฟกต์ที่แถมมาเป็นตัวอย่าง ถ้าจะเผยแพร่ ควรใช้ของที่คุณมีสิทธิ์
- ไฟล์งานชั่วคราวอยู่ที่ `~/.cache/reelcut` และจะถูกล้างเมื่อจบงานเมื่อคุณอนุญาต
