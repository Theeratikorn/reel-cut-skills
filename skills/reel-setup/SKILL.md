# reel-setup — ติดตั้ง + สัมภาษณ์ + ตั้งค่าให้เป็นของผู้ใช้

## บทบาทของคุณ
ผู้ใช้ส่วนใหญ่ **ไม่มีพื้นฐานเทคนิค** และ **ไม่ใช่เจ้าของสกิล** — ชุดนี้ไม่มีแบรนด์/ชื่อ/ข้อความของใครติดมา ทุกอย่างต้องมาจากสิ่งที่ผู้ใช้บอกเท่านั้น
ทำตามที่เขาสั่ง พูดภาษาไทยง่ายๆ ไม่ใช้ศัพท์ (ไม่พูด brew, PATH, clone, JSON ให้พูดว่า "ติดตั้งโปรแกรมตัดต่อ" "บันทึกการตั้งค่าของคุณ") ทำเองให้ครบ ถามเฉพาะที่จำเป็นจริง รายงานสั้นๆ ว่าเสร็จหรือติดอะไร

## ลำดับ
1. **ตรวจเครื่อง** `bash ~/.claude/skills/reel-setup/scripts/doctor.sh` (ถ้ายังไม่ได้ติดตั้งสกิล ให้โคลนตาม INSTALL.md ก่อน) สรุป ✅/❌ เป็นภาษาง่ายๆ
2. **บอกว่าจะติดตั้งอะไร ขอ "ได้" ครั้งเดียว:** โปรแกรมตัดต่อ (ffmpeg), Node.js, Python numpy ผ่าน Homebrew · ฟอนต์ Kanit/Noto Sans Thai/Caveat (ดาวน์โหลดจาก Google Fonts รวมประมาณ 1 MB) · ไฟล์สกิลจาก GitHub ลง `~/.claude/skills`
3. **ติดตั้ง** รัน `install.sh` (ในโฟลเดอร์ที่โคลนมา) — ถ้าไม่มี Homebrew ให้ผู้ใช้เปิดแอป Terminal ทำตามหน้า brew.sh เอง (ต้องใส่รหัสผ่านเครื่อง ห้ามทำแทน)
4. **สัมภาษณ์ → โปรไฟล์** (หัวข้อถัดไป) ทำก่อนทดสอบ เพื่อให้ผลทดสอบ/ตัวอย่างเป็นสีและสไตล์ของผู้ใช้
5. **รหัส ElevenLabs** (ถอดเสียง): ผู้ใช้ต้องสมัคร/ล็อกอิน elevenlabs.io เองแล้วคัดลอก API key (ขึ้นต้น `sk_`) มาวางในแชต — สร้างบัญชีหรือกรอกรหัสในเว็บแทนไม่ได้ เมื่อได้แล้วเขียนลง `~/.config/reelcut/env` (บรรทัด `export ELEVENLABS_API_KEY=…`, `chmod 600`) **ห้ามพิมพ์รหัสซ้ำในคำตอบ** ห้ามเก็บที่อื่น (มีค่าใช้จ่ายตามการใช้งานของบัญชีผู้ใช้ — บอกให้รู้)
6. **ทดสอบ** `bash ~/.claude/skills/reel-setup/scripts/selftest.sh` (ตัดคลิปทดสอบ 5 วินาที ไม่ใช้เครดิต) ผ่านแล้วบอกว่า "พร้อมแล้ว"
7. **บอกให้ปิดแล้วเปิด Claude Code ใหม่ 1 ครั้ง** แล้วลองพิมพ์ "ตัดคลิปล่าสุดใน Downloads ให้หน่อย"

## การสัมภาษณ์ (สร้างโปรไฟล์ของผู้ใช้)
เป้าหมาย: รู้ว่าผู้ใช้เป็นใคร ทำคอนเทนต์อะไร อยากให้ผลงานหน้าตาแบบไหน แล้วตั้งสกิลให้เป็น "ของเขา"
**กติกา:** ถามทีละรอบ รอบละ 1–3 ข้อ (ใช้เครื่องมือถามแบบมีตัวเลือกถ้ามี) ให้ตัวอย่างคำตอบทุกข้อ · ข้อไหนไม่รู้/ไม่อยากตอบ = "ข้ามได้" ใช้ค่ากลาง ไม่ตื๊อ · **ห้ามเดา ห้ามแต่งชื่อ/ช่องทางติดต่อ/ข้อความให้** · ก่อนบันทึกต้องสรุปให้ผู้ใช้ยืนยัน

| รอบ | ถามอะไร | เก็บใน (คีย์โปรไฟล์) |
|---|---|---|
| 1 ตัวตน | ให้เรียกว่าอะไร · มีชื่อช่อง/แบรนด์ไหม · ทำคลิปเรื่องอะไร (เช่น ติววิชา, รีวิว, ท่องเที่ยว, ขายของ) · ผู้ชมคือใคร | `name` `brand` `niche` `audience` |
| 2 ลักษณะคลิป | คลิปแบบไหน (พูดหน้ากล้อง / สอนหน้ากระดาน / มีการทดลอง / อื่นๆ) · อยากได้ยาวประมาณกี่วินาที (30/60/90) · พูดภาษาอะไร | `clip_types` `target_seconds` `language` |
| 3 หน้าตา | พื้นหลังตอนถ่ายสว่างหรือมืด (ไม่แน่ใจ → ขอดูคลิปตัวอย่าง 1 คลิป แล้วบอกเอง) · สีหลักของแบรนด์ (ไม่มี → เสนอ 3–4 สี) · **เปิดพรีวิวสไตล์ให้ดู** (`open ~/.claude/skills/reel-cut/styles/preview.html` และ `sketch_sheet_preview.html`) แล้วให้เลือกเลขที่ชอบ · อะไรที่ไม่ชอบ (เช่น ภาพรก ตัวหนังสือเยอะ) | `wall` `accent` `style` `dislikes` |
| 4 ข้อความ | ชื่อซีรีส์/หมวดที่จะขึ้นป้ายกลางจอ · อยากให้ท้ายคลิปชวนทำอะไร (เช่น "กดติดตาม") · ช่องทางติดต่อที่อยากโชว์ (หรือไม่โชว์) | `series` `cta_end` `cta_handle` |
| 5 เสียง/ไฟล์ | ใช้เพลงพื้นหลังไหม (ไม่ใช้ / ใช้ / ถามทุกครั้ง) — **เพลงและเสียงเอฟเฟกต์ที่แถมมาเป็นตัวอย่าง ถ้าจะเผยแพร่ ควรใช้ของที่ผู้ใช้มีสิทธิ์** · เก็บไฟล์ที่ไหน (ค่าเริ่มต้น ~/Movies/ReelCut) · ถ้าเป็นเนื้อหาวิชาการ อยากให้ตรวจความถูกต้องของเนื้อหาให้ไหม (เช่น ฟิสิกส์) | `music` `out_dir` `subject_checks` |

**บันทึก:** สรุปคำตอบเป็นรายการสั้นๆ ให้ผู้ใช้ตอบ "ถูก" แล้วรัน
```bash
python3 -I ~/.claude/skills/reel-cut/scripts/reelprofile.py save <<'JSON'
{ "name": "...", "brand": "...", "niche": "...", "accent": "#RRGGBB", "wall": "light", "style": "sketch-sheet", ... }
JSON
```
(ใส่เฉพาะคีย์ที่ผู้ใช้ตอบ; สคริปต์ตรวจรูปแบบและรวมกับค่าเดิมให้ ถ้าขึ้น error ให้แก้ตามข้อความแล้วลองใหม่) แล้ว `reelprofile.py show` ยืนยัน
- ค่าสี `accent` ต้องเป็นรหัส `#RRGGBB` (แปลงชื่อสีที่ผู้ใช้บอกให้) · `wall` = `light` หรือ `dark` · `style` = รหัสในคลัง (`reel-cut/styles/README.md`; ค่าเริ่มต้น `sketch-sheet`)
- **เปลี่ยนทีหลัง:** ผู้ใช้พูดว่า "เปลี่ยนสี/สไตล์/ข้อความท้ายคลิป" → ถามค่าใหม่ แล้ว `save` เฉพาะคีย์นั้น

## อัปเดต
รัน `bash ~/.cache/reelcut-src/install.sh` อีกครั้ง (รันซ้ำได้ ไม่ลบงานเก่า ไม่ลบโปรไฟล์)

## ถ้ามีปัญหา
รัน `doctor.sh` ก่อนเสมอ แก้ทีละข้อที่ ❌ · อย่าลบ `~/.cache/reelcut` (งานค้างอยู่) หรือ `~/.config/reelcut` (โปรไฟล์/รหัส) · อย่าลบไฟล์ใน Downloads/Movies ของผู้ใช้
