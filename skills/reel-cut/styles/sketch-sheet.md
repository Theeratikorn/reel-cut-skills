# สไตล์ "Split Screen · สเก็ตช์ปกชีท" (สเปกงานภาพ)

ที่มา: สไตล์ที่ผู้สร้างต้นฉบับใช้กับคลิปสอนวิทยาศาสตร์ชุดหนึ่ง (ใช้เป็นค่าเริ่มต้นของระบบ; ปรับสี/ข้อความได้ผ่านโปรไฟล์ผู้ใช้)
ขอบเขตไฟล์นี้: **เฉพาะงานภาพ** (หัวข้อ 1–6 ของสเปกเดิม) — เรื่องการตัด/เสียง/ส่งไฟล์ใช้ของ reel-edl / reel-audio / reel-deliver ตามเดิม
พรีวิวเล่นได้: `sketch_sheet_preview.html` (ภาพคนเป็นตัวจำลอง) · **สถานะ: ต้นแบบเบราว์เซอร์ ยังไม่เคยเรนเดอร์ใน HyperFrames, ยังไม่เป็นพรีเซ็ตใน hflib, ยังไม่ได้ตั้งเป็นค่าเริ่มต้น**

## 1. เลย์เอาต์ (1080×1920)
- Hook: หน้าเต็มจอ 2–4 วินาทีแรก หรือเฉพาะประโยคเปิด
- โหมดหลัก split: **บน 1080×960 พื้นขาวล้วน = แผงอนิเมชัน** · **ล่าง = วิดีโอ** ครอปให้เห็นผมถึงอก (ตัดที่ y=660 ของต้นฉบับ; คลิปการทดลองใช้ 520)
- ทรานซิชัน: วิดีโอเลื่อนลงครึ่งล่างใน 0.5s `ease in-out` ครึ่งบนขาวโผล่ขึ้น ตอนพี่เริ่มอธิบายเนื้อหา
- รอยต่อ: แถบม่วงแดงหนา 10px + **ป้ายเม็ดยา** (พื้นขาว ขอบม่วงแดง) ทับกลาง ใส่ชั้น·หัวข้อ เช่น "<ซีรีส์> · <หัวข้อ>"; ท้ายคลิปเปลี่ยนเป็นคำชวน "กดเซฟ · แชร์ให้เพื่อน" / "คอมเมนต์คำตอบ!"
- แถบความคืบหน้า: ม่วงแดง สูง 10px ขอบบนสุด
- คลิปการทดลอง (แบบมีการทดลอง): ท้ายคลิปกลับเต็มจอเพื่อโชว์การทดลองอีกรอบ

## 2. สีและฟอนต์
| ใช้กับ | สี |
|---|---|
| เส้น/ตัวหนังสือหลัก | กรมท่า `#1d3557` |
| จุดสำคัญ (จุดเดียวต่อฉาก) | ม่วงแดง `#DB2777` |
| เส้นบอกระยะ มุม ป้ายลายมือ | ส้ม `#e07b24` |
| หน้าบน/ข้างกล่อง 3D | พีช `#fbe3cf` / `#f6d2b5` |
| คำอธิบายรอง | เทา `#5b6577` |
- ตัวหลัก **Noto Sans Thai** (หัวข้อ 800, คำอธิบาย 600) — ติดตั้งในเครื่องแล้ว (variable font)
- ป้ายลายมือ **Caveat** สำหรับ F h s v θ r และ "Lami's Theorem" — **ยังไม่ได้ติดตั้งในเครื่อง** (พรีวิวโหลดจาก Google Fonts) ต้องดาวน์โหลดเข้า `hf/` เหมือน Kanit ก่อนเรนเดอร์จริง
- หัวข้อฉาก: มุมซ้ายบน 56px ขีดม่วงแดงนำหน้า เช่น "▌สูตรที่ 1"

## 3. ลายเส้นแบบปกชีท
- เส้นกรมท่าหนา ~5–8px ปลายเลยมุมนิดหน่อยแบบวาดมือ
- วัตถุ 3D isometric: หน้าตรงขาว, หน้าบน/ข้างพีช, ข้างมีเส้นแรเงาแนวตั้ง
- พื้น: เส้นเทาอ่อนสองชั้น + เงาจาง; พื้นเอียง/พื้นทะเลแรเงาเส้นเฉียง
- เส้นบอกระยะส้ม ขีดปลายสองข้าง ป้ายลายมือ
- ลูกศรแรง: ตัวที่กำลังพูดถึง = ม่วงแดง ที่เหลือกรมท่า
- **boiling line:** เส้นทุกเส้นสั่นเบาๆ ~7 ครั้ง/วินาที ส่วนตัวหนังสือ/สมการ **ไม่สั่น**
- **ความถูกต้อง:** มุม ความยาว ทิศของลูกศรคำนวณตามฟิสิกส์ เช่น ลามี: ความยาวลูกศร ∝ sin(มุมตรงข้าม) (พรีวิวคำนวณให้ ผลรวมเวกเตอร์ = 0)

## 4. อนิเมชัน
- ทุกอย่างขึ้นตามคำพูด: เวลาของชิ้นจาก timestamp ระดับคำของ ElevenLabs (`ph.py` → `m(t)`)
- ท่าเข้า: ตัวหนังสือ/สมการ pop 60%→100% ใน 0.32s · เส้นถูกวาดตามแนวเส้น · หัวข้อฉากเลื่อนเข้าจากซ้าย
- ไฮไลต์: ตัวที่พูดถึงเป็นม่วงแดง แล้วกลับสีเดิมเมื่อพูดตัวถัดไป (F₁→F₂→F₃, มุม θ มีพื้นสีจาง)
- ทุกฉากต้องมีภาพเคลื่อนไหวต่อเนื่อง ≥ 1 อย่าง: คลื่นวิ่ง ลำโพงเต้น เข็มจับเวลา, ของเหลวเทอร์โมมิเตอร์, โมเลกุลอากาศ, พัลส์โซนาร์ไป-กลับ, เรือโคลง, คานหมุน, ลูกบอลวนวงกลม, คนเดินเข้า-ออก, อนุภาคลมช้า/เร็ว, กระดาษโค้งหุบ, สมการลอยขึ้นลงเบาๆ, "?" เด้ง
- ฉากสรุปท้ายคลิป: รวมสูตรทั้งหมด หน้าบรรทัดมีเลขในวงกลมม่วงแดง ขึ้นทีละบรรทัด

## 5. สมการบนจอ
- เศษส่วนแบบซ้อน (เศษบน เส้นคั่น ส่วนล่าง) ไม่ใช้ a/b — ใช้ `.frac` + `.fbar` (div สูง ~6px; `border-bottom` ไม่ขึ้น)
- √ คลุมทั้งเศษส่วน · พิสูจน์หลายบรรทัด แยกบรรทัดละขั้น เรียง = ให้ตรงกัน
- ตัวแปร: t ตัวเล็ก = เวลา, T ตัวใหญ่ = อุณหภูมิ (แม้พี่พูด "t" ทั้งสองแบบ)
- หน่วย/เงื่อนไข: ตัวเล็กสีเทา หรือป้ายม่วงแดง เช่น "T ใช้หน่วย K"

## 6. Hook
- แบบปกติ (พูดหน้ากล้อง): ตัวกรมท่ามีเงาเรืองขาว ลอยเหนือหัว 4 ชั้น — ป้ายชั้น/บทม่วงแดง · หัวเรื่อง 112–128px · คำอังกฤษลายมือส้ม · คำถามชวนดู
- แบบการ์ด (แบบมีการทดลอง): การ์ดขาวทึบ แถบม่วงแดงด้านซ้าย วางช่วงบนสุดของภาพ ไม่บังการทดลอง
- สั้น: ใช้แค่ประโยคเปิด ตัดท่อนพูดซ้ำ

## ข้อควรระวังตอนย้ายเข้า HyperFrames (ยังไม่ได้ทดสอบ)
- **boiling line ต้อง deterministic:** seed ของ `feTurbulence` = `floor(t*7)` จาก timeline ไม่ใช่ wall-clock (พรีวิวใช้ `gsap.ticker` ซึ่งใช้เรนเดอร์จริงไม่ได้) และ SVG filter เรนเดอร์ช้า ต้องวัดเวลาเรนเดอร์
- เปลี่ยนข้อความด้วย `textContent` ผ่าน callback **ไม่ปลอดภัยต่อการ seek** → ใช้สองป้ายแล้ว crossfade (พรีวิวทำแบบนี้แล้ว)
- ครึ่งล่างต้องครอปวิดีโอจริง (y=660 / คลิปการทดลอง 520) ด้วย ffmpeg ตอนตัด ไม่ใช่เลื่อน element — พรีวิวใช้ตัวจำลอง
- ห้ามเติมข้อเท็จจริงที่ไม่ได้พูด; ต้องแจ้งข้อความที่เติมเองทุกครั้ง
