## กฎร่วม (ทุกสไตล์)
- ข้อความอยู่เหนือหัว (y ~370–750) ไม่ทับหน้า; ธีมสี light/dark ตามผนังเหมือนเดิม
- ม่วงแดง `#DB2777` เป็น accent เดียว; Kanit Bold; ห้ามเติมข้อเท็จจริงที่ไม่ได้พูด
- เวลาเริ่มของแต่ละองค์ประกอบมาจาก `m(เวลาในต้นฉบับ)` ตามคำพูด ไม่ใช่เวลาตายตัว
- ข้อควรระวังเทคนิคของ #4: path ต้องวาดตามตำแหน่งข้อความจริง (ดูเฟรมก่อน) และ GSAP ห้ามสั่ง transform บน element ที่มี CSS `transform`
